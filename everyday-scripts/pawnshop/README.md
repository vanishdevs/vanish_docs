# 💰 Pawnshop

## Features

* Sell items for cash and buy from a configurable stock list, all from one ped,
* Optional opening hours so the shop is only usable during a set window,
* Sell everything in one click, or pick items one at a time,
* Prices are set per item, with full control over the label and icon shown in the menu,
* Separate buy and sell lists, each can be turned on or off on its own,
* Configurable ped model, scenario and as many shop locations as you want,
* Optional map blip with your choice of sprite, colour and scale,
* Framework bridge included for ESX, QB, QBOX and ox\_core
