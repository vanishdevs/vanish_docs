# Guides

Use these pages when you want the workflow view instead of the config reference.
The admin guide is for staff building and maintaining gangs. The management
guide is for gang leaders using the in-game menu day to day.

* [Gang Administration](gang-administration.md) covers creating gangs, creating ranks, setting passcodes and handling destructive admin actions.
* [Gang Management](gang-management.md) covers invites, member control, stash access and the leader-facing menu.
* [Advanced Gang Operations](advanced-gang-operations.md) covers newer tools like templates, recruitment, stash limits, health score and relationships.

{% hint style="info" %}
Start with the admin guide when setting up the resource for the first time. Hand
the management guide to trusted gang leaders once the ranks and permissions are
ready.
{% endhint %}
